Privacy Policy

PB Workspace CLI · Last updated: September 20, 2026

Summary: PB Workspace CLI is a single-user, locally installed program that accesses only its owner's own Google account data. That data stays on the owner's computer. Nothing is sent to the developer or to any third party.

1. Who this applies to

PB Workspace CLI ("the application") is a private command line tool installed on its owner's own computer. It has exactly one user — its owner, who is also its developer. There is no public sign-up, no website accounts, and no other users' data involved.

2. What Google user data is accessed

When the owner authorizes the application through Google's OAuth consent screen, it may access the following data belonging to the owner's own account:

  • Google Calendar — calendars and events, to list and create events.
  • Gmail — messages, to search and read them, and to send mail from the owner's own address.
  • Google Drive — files and folders, to list, read, upload, and organize them.
  • Google Docs and Sheets — document content, to read and edit it.
  • Google Contacts — the owner's contact entries, to read and look them up.
  • Basic identity — the owner's email address, used to label the local credential.

Access is limited to these functions. The application does not request scopes it does not use.

3. How that data is used

Data is used solely to perform the operations the owner explicitly requests at the command line — for example, listing today's calendar events or searching their own mailbox. The application does no background processing, no analytics, and no profiling.

4. Storage

OAuth credentials and refresh tokens are stored locally on the owner's computer, in a password-protected local keyring file readable only by the owner's operating system account. No copy of any Google user data is uploaded anywhere. Cached command output, if any, exists only as local files the owner's own scripts produce, and the owner can delete it at any time.

5. Sharing and disclosure

No Google user data is transmitted to, shared with, sold to, or disclosed to any third party. There are no analytics providers, no advertising networks, no data brokers, and no remote servers operated by the developer. The only network destinations the application contacts are Google APIs themselves, over HTTPS, in order to fulfil the owner's command.

6. No advertising, no model training

Google user data obtained through this application is never used for advertising, ad targeting, or profiling of any kind. It is never used to train, fine-tune, or evaluate machine-learning models, and it is never transferred to any party for those purposes.

7. Google API Services User Data Policy — Limited Use

PB Workspace CLI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: data is used only to provide the user-facing features described above; it is not transferred to others except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition; it is not used for advertising; and it is not used to determine creditworthiness or for lending purposes.

8. Revoking access and deletion

The owner can revoke the application's access to their Google account at any time at myaccount.google.com/permissions. Deleting the local credential files on the owner's computer removes the stored tokens entirely. Because the developer holds no copy of any user data, uninstalling the application and revoking access is a complete deletion of everything the application ever touched.

9. Children's privacy

The application is not directed at children and has no users other than its owner.

10. Changes to this policy

Any material change to this policy will be published on this page with an updated revision date.
